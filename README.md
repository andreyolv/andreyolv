# Andrey Oliveira

**Golden Kubestronaut · SRE · Data Platform Engineer · FinOps**

Building secure, resilient, and cost-efficient AI & Data Platforms at scale.

I use GitHub to share the cloud-native and platform engineering work I do — reference
architectures, Kubernetes operators and controllers, GitOps setups, reusable CI/CD workflows,
automation, and the documentation that makes them maintainable. Great platforms are built on
timeless engineering principles, so I optimize for long-term maintainability, operational
excellence, clear governance, and avoiding unnecessary complexity.

I'm a strong advocate for open source — not simply to reduce licensing costs, but to build
flexible, vendor-neutral platforms with an exceptional long-term cost-benefit ratio. That shows
up here as hands-on contributions and discussions across projects such as Apache Airflow, Trino,
ClickHouse, StarRocks, Redpanda, Velero, Backstage, Crossplane, and External Secrets.

I also maintain [Universidade Livre de Dados](https://github.com/andreyolv/UniversidadeLivreDeDados),
a free collection of 80+ academic disciplines on Big Data and AI.
